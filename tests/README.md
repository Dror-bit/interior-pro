# בדיקות — Interior Pro

חבילת בדיקות שרצה **מחוץ לסקצ'אפ**. היא טוענת את קבצי הרובי האמיתיים של
התוסף מעל סטאב של SketchUp API, ואת ה-JavaScript של העורך היא מחלצת מתוך
ה-heredoc בדיוק כמו שרובי היה עושה בזמן ריצה.

## למה זה קיים

`plan_editor.rb` מחזיק את כל ה-HTML/JS של העורך בתוך heredoc. escape בודד
שם הורג את כל ה-JavaScript בשקט — הקנבס פשוט מת בלי שגיאה. החבילה הזאת
תופסת את זה, וגם בודקת את הגיאומטריה עצמה: הצמדות, מיטרים, שטחי חדרים,
שרשראות מידה וכן הלאה.

בסבב שבו היא נבנתה (2026-08-01/03) היא תפסה שישה באגים אמיתיים לפני
שהגיעו למשתמש, כולל אחד ישן: שתי צורות יכלו לקבל אותו מזהה, ואז מחיקה
הייתה עלולה לפגוע בצורה הלא נכונה.

## איך מריצים

```
bash run_all.sh /path/to/interior_pro
```

בלי ארגומנט הוא מניח שהתוסף נמצא בתיקייה שמעל. הסקריפט מעתיק אליו את
קבצי התוסף החיים, מחלץ מחדש את ה-JS, ומריץ הכל. יציאה שונה מאפס = משהו
נכשל.

דרישות: `ruby` ו-`node` בנתיב.

## מה יש כאן

`extract.rb` מחלץ את ה-HTML/JS מה-heredoc של `plan_editor.rb` — נותן לרובי
עצמו לעבד את ה-escapes, ואז כותב `out.html` ו-`out.js`.

`stub.js` הוא DOM ו-Canvas מזויפים. הוא מקליט כל קריאת `fillText`,
`stroke` ו-`rotate`, כך שבדיקה יכולה לשאול "כמה מספרים צוירו, באיזו זווית,
ובאיזה צד של הקיר". `run.js` טוען את `out.js` מעליו ופותח גישה למשתנים
ולפונקציות הפנימיות.

`sketchup_stub.rb` ו-`geom_stub.rb` הם SketchUp API מינימלי — קבוצות,
attributes, entities, נקודות, וקטורים וטרנספורמציות. הם מספיקים כדי
להריץ את `room_manager.rb` ו-`plan_generator.rb` האמיתיים.

`t*.js` — חבילות של העורך: מחק קטעים, הזזה/סיבוב/אופסט בשיטת סקצ'אפ,
בחירה, הצמדות, חדרים ושטחים, מידות ותמונת רקע.

`rt*.rb` — חבילות רובי: ה-callbacks של הדיאלוג, מזהים ייחודיים, חדרים,
שרשראות מידה בתוכנית, ופתח ללא דלת.

## אזהרה

הבדיקות מעתיקות אליהן את קבצי התוסף. הן **לא** כותבות שום דבר בחזרה
לתיקיית התוסף.
