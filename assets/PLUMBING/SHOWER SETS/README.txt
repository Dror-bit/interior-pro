SHOWER SETS - one folder per set (the folder name = the set name).

Inside each set folder, one .skp file per part, with EXACTLY these names:
  head.skp    - shower head
  valve.skp   - handles / valve
  hand.skp    - hand shower (optional)
  spout.skp   - tub spout (optional)
A part with no file is simply not in the set.

Each file, before saving:
  - the part sticks out of the wall toward the GREEN axis (+),
    its back flat against the wall (the red-blue plane)
  - the point where the pipe comes out of the wall sits on the ORIGIN
    (where red, green and blue meet)

COLOURS (2026-09-28): a set folder may hold one folder per colour instead
of the parts, e.g.  Set 1/Black/head.skp  and  Set 1/Brushed Nickel/head.skp.
The window shows the set once, and its colours underneath.
Each colour folder can have its own thumb.png.
