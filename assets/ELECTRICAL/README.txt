Interior Pro - ELECTRICAL products (2026-10-12)

One .skp file = one product. Put outlets in OUTLETS\ and switches in SWITCHES\.
The name of the file is the name in the window.

How a file is placed on the wall:
  - its BACK (the lowest green / -Y side) goes on the wall face
  - the middle of its width (red / X) sits on the line you click or type
  - the middle of its height (blue / Z) sits at the height you type in the window

Draw it standing up, facing +green (the front of the plate toward +Y), with the
back flat on the red-blue plane. Hidden things in the file are left out.

Pictures: made by SketchUp the first time the window opens (thumbs\<name>.png).
After changing a file that was already placed: Window > Model Info > Statistics >
Purge Unused, then place it again (an old copy in the model wins over the file).

"Save selected" in the window saves ONE selected group / component from the model
into this folder as a new product.
